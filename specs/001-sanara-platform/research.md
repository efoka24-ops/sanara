## 2. Décision : HTTP provisoire

Le propriétaire a décidé de travailler en HTTP pour l'instant. Règles associées (constitution v1.0.1) :

1. **Uniquement des données de test** tant que le site est en HTTP : aucune vraie ordonnance, aucun vrai patient, aucun vrai mot de passe de pharmacie.
2. Les mots de passe transitent en clair en HTTP : n'utiliser que des comptes de test jetables.
3. Les cookies de session sont posés **sans** `Secure` en développement seulement, via un réglage d'environnement ; en production `Secure`, `HttpOnly`, `SameSite=Lax` obligatoires.
4. Le passage en HTTPS (certificat Let's Encrypt via Camoo) est **un prérequis de la mise en production et de toute pharmacie réelle** (tâche T001a).
5. Le desktop et le web utilisent une variable `APP_URL` : le basculement HTTPS ne doit demander aucun changement de code.

## 4. Stratégie de déploiement sur Camoo

- Racine = `/home/trugro9159/sanara`. Structure déployée :
  - `/` : build statique du front (`index.html`, `assets/`), `.htaccess` (réécriture SPA, en-têtes de sécurité).
  - `/api/` : point d'entrée Slim (`index.php`) + `.htaccess` ; le code PHP (`app/`, `vendor/`, `database/`) est placé dans `/api-core/` protégé par `Deny from all`, seul `/api/index.php` est exposé.
  - `/storage-private/` : documents chiffrés, `Deny from all`.
  - `/desktop-releases/` : binaires et métadonnées de mise à jour du desktop.
- `.env` serveur placé hors des chemins exposés et protégé en refus total.
- Déploiement par script FTP (`infra/deploy/deploy.ps1`) en deux temps : envoi vers un dossier de préparation, puis bascule rapide pour limiter l'indisponibilité.
- Migrations exécutées par un endpoint protégé (jeton + liste d'IP) ou par un script cron à usage unique, jamais accessible publiquement.
- Sauvegardes MySQL par cron (dump compressé et chiffré) conservées hors racine.

## 6. Constats de mise en œuvre (2026-11-24, premier déploiement)

| Constat                                                                                                                                                                                                         | Conséquence                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.htaccess` : les directives `Options` et `DirectoryIndex` provoquent une erreur 500 (surcharge interdite) ; `Header`, `FilesMatch`/`Require`, `RewriteRule` fonctionnent                                       | `root.htaccess` n'utilise que les directives autorisées ; `mod_rewrite` est **disponible** (routage `/api/...` et repli SPA validés)                                                                                   |
| Le pare-feu applicatif renvoie **400 (HTML Apache)** pour toute séquence `\uXXXX` dans le corps d'une requête (par exemple `é` ou `'`) et pour un JSON mal formé ; accents, apostrophes et emojis bruts passent | Le client API ne doit jamais envoyer de séquences `\u` : sérialiser en UTF-8 brut (`JSON.stringify` suffit sauf caractères de contrôle) ; prévoir un repli encodant le corps en base64 si un texte saisi contient `\u` |
| Apache renvoie **403** à toute requête `PUT`, `PATCH` ou `DELETE` sur `/api` (constaté le 2026-11-26)                                                                                                           | Le client envoie un `POST` avec l'en-tête `X-HTTP-Method-Override`, que `MethodOverrideMiddleware` rétablit                                                                                                            |
| MySQL refuse une valeur plus longue que le `VARCHAR(n)` déclaré, SQLite l'accepte (erreur 500 en préproduction seulement)                                                                                       | `TestDb` fait respecter les longueurs pendant les tests ; élargissements MySQL dans des fichiers `*.mysql.sql`                                                                                                         |
| `.user.ini` posé dans `/api/` : les limites d'envoi restent à 2 Mo / 8 Mo à la première vérification                                                                                                            | À revérifier après expiration du cache (≈ 5 min) ; sinon compression des photos côté navigateur obligatoire                                                                                                            |
| Pest exige PHP 8.2 ; `firebase/php-jwt` 6.x est sous avis de sécurité                                                                                                                                           | PHPUnit 10 et `firebase/php-jwt` 7                                                                                                                                                                                     |
| Mots de passe contenant `#` ou `%` dans `.env` : lus tronqués s'ils ne sont pas entre guillemets                                                                                                                | Le script de déploiement met toutes les valeurs entre guillemets simples                                                                                                                                               |
| FTP simple uniquement (pas de FTPS)                                                                                                                                                                             | Déploiement par archive unique + extracteur à usage unique supprimé après exécution                                                                                                                                    |
